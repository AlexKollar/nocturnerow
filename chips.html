Chips

Cartridge tools for Apex, powered by Navi. Each picture below is the chip itself — the code rides inside the image. Download one and drop it into Apex, and Navi can run it. No installers, no app store.

Eight chips, free and open. The newest seven — netkit through linuxkit — were built course-by-course for a cybersecurity degree program; cryptex, the cryptography toolkit, came first. Every chip runs fully offline.

Navi Netkit

v1.0.0 · navi-chip/1

Networking fundamentals for cybersecurity students: subnet and CIDR math, an offline port/service reference, IP classification and MAC parsing — pure computation, fully offline.

Download .pngGitHub

Navi Scribe

v1.0.0 · navi-chip/1

A log reader and report writer: paste log lines in, get the structure, the timeline, the lines that matter, and a findings draft in report language. Standard library only.

Download .pngGitHub

Navi Recon

v1.0.0 · navi-chip/1

Port scanning and service fingerprinting for your own lab: TCP connect scans with a banner read and a defender's explainer on every open port. Public addresses are refused unless you assert ownership.

Download .pngGitHub

Navi Hashlab

v1.0.0 · navi-chip/1

A password & hash lab companion: identify hashes by shape, crack lab-provided hashes with a built-in wordlist, and learn strength from entropy and crack times — standard library only.

Download .pngGitHub

Navi Syskit

v1.0.0 · navi-chip/1

A hardware and Windows Server workbench: A+ hardware reference, symptom-to-cause diagnostics, server admin cheat pages and planning drills — fully offline, standard library only.

Download .pngGitHub

Navi Cisco

v1.0.0 · navi-chip/1

A CCNA companion for the CIS 170/171/172 spine: ACL builder with placement reasoning, VLAN planning with config skeletons, OSPF basics and troubleshooting, an IOS survival reference, and wireless topics — knowledge and config text only, fully offline.

Download .pngGitHub

Navi Linuxkit

v1.0.0 · navi-chip/1

A Linux administration workbench: the admin command reference with the traps included, permission math both ways, hardening checklists, and an FHS map — standard library only, fully offline, and it executes nothing.

Download .pngGitHub

Navi Cryptex

v2.0.3 · navi-chip/1

The cryptography toolkit: classical ciphers, encodings, and hash utilities — 22 commands, standard library only. The first chip, rebuilt from scratch.
