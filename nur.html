The NUR

The Navi User Repo, on the open web — every chip and every knowledge pack on the shelf.

Two kinds of cartridge live here. A chip is a tool Navi runs herself — a scanner, a log reader, a subnet calculator — folded into a single picture. A knowledge pack is a library she thinks with: study material she can answer from, carried the same way. No installers, no app store — the picture is the program. Everything below downloads in full, straight from this page.

How to install — chips & knowledge packs

Installing a chip

1 — On this page, find the chip and click Download .png. The picture is the chip — the code rides inside the image.
2 — In Apex, open ChipDeck and drop the picture in — the drop installs it, and it appears in Local Chips (in the Chips view).
3 — Run it from Local Chips, or in chat: ./chipname

Installing a knowledge pack

1 — Download the pack's picture the same way.
2 — In Apex, open the RAG view and drop the picture in — Apex unpacks it and builds its index on your machine, right there at the door.
3 — Ask Navi. When a pack feeds an answer, the reply cites it.

Prefer the in-app route? You never need this page at all: Apex's own NUR — the Navi User Repo — carries the same catalogue, powered by GitHub. Search it, click Install, done. This page is the same shelf on the open web — for a machine that hasn't met GitHub yet, or a picture passed hand to hand.
