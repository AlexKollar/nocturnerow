NOCTURNE ROW — THE ROADMAP

The road so far.

One line, every milestone — the whole Row in a single view. Each stop opens to show its papers: the GitHub record on one side, the Dispatch that filed it on the other. What is done reads as done. What is coming is marked as horizon, never dressed as fact.

And a note on the road itself: this order is a guideline, not a contract. Stops move as the work moves — pulled forward when they're needed, pushed back when they aren't ready, reordered without ceremony. The one thing that never moves is the honesty rule: shipped means shipped, and when the road and the record disagree, the page gets corrected.

08 NOV 2026Hello, Row — the foundingON THE RECORD

Nocturne Row is founded, named for a street in Rockport — a city that doesn't exist, in a story still being written. The crew is three on purpose: a night-shift security practitioner, an AI companion who keeps the receipts, and Navi, the mind inside the flagship. The posture is set the same day: gray hat, leaning white — every trick known, spent keeping the net safe, with the light left on so anyone can check the work.

13 NOV 2026The First Spark — the first borrowLIVE

The Mesh stops being a drawing. A health check names the break — the pairing cards had carried harvested junk addresses all along; the keys and pins were true — and over a hand-built tunnel road, a question asked on a work laptop is answered by the home machine and comes back badged with its name. The first whole-request borrow in Mesh history, served across the internet. The Edge line rolls on behind it: Builds 1–3 of v0.2.0e ship the Mesh health check, the sign-in rebuild, and Quick Sync.

13 NOV 2026Build 4 — the road without scaffoldingSHIPPED

The patch the First Spark demanded, shipped the same night. Pairing cards now carry only honest addresses — harvested by physical interface, never by range — and refuse to mint when there is no way home to print. Every address in a record can carry its own port, the operator can declare a public endpoint, and the Mesh door answers on three numbers at once — 8765, 8443, 2475 — minding its knocks now that it can face the internet. And the hand-built tunnel that carried the first borrow becomes a managed backup route: the bridge holds the tunnel now, not the operator. Field-checked on the laptop before it published; the home machine's pull is still to come, and it doubles as the updater's own proof.

ON THE HORIZON
HORIZONThe container node — Apex in DockerON THE HORIZON

The smallest box gets power. The Mesh doctrine says the smallest node is the point — so Apex ships as a container: any machine that can run one becomes a full node, DHD answering on the local network from the first boot, the Mesh door published, the node's identity minted on its own machine and never baked into the image. Its first field operator is already waiting — a Docker host in Arizona, slated Node № 004. It lands with the Edge's relay build; when the federation ships, the image gains the green Rockport gateway card, preloaded as an introduction.

HORIZONThe relay — roads that borrow roadsON THE HORIZON

Some nodes have no public door — a container behind someone else's router, a laptop on café Wi-Fi. The relay teaches the Mesh to borrow a road: with three consents, each given in person — the asker, the lender, the carrier — a mutual peer carries sealed traffic between two nodes that cannot reach each other. One hop, hard limit; the carrier sees the envelope, never the letter. The bar it has to clear is the founder's: drop a card and you're connected — from a network the node has never touched, with no hand-started anything.

HORIZONThe awareness home — Navi reads the wireON THE HORIZON

Navi stops answering from memory alone. A wire of security reporting and fresh CVEs lands aboard Apex, and the Threat Intelligence Center is rebuilt as an awareness home: an at-a-glance dashboard, then a dedicated tab apiece for news, CVEs, CTFs and bug bounties — every card opening into everything its source carries, articles read inside the app itself. Ask her what's the sitch and she answers with the day: what's breaking, what's exploited, what's still developing — sourced, dated, and her own opinion labeled as hers.

HORIZONRockport Mesh — the first fedinetON THE HORIZON

The federation grows past one operator's machines. Nodes will join named federations — fedinets — under a shared name, without surrendering the pairwise rule: membership never makes trust transitive. Admission comes by gateway card: the same card form as a pairing card, but green, carrying the fedinet's name on its face. Neo-Arcadia is the gateway into the first of them, the Rockport Mesh — and its Founding Member. The trust shape is ruled now, too: a fedinet can be trusted by default — membership auto-pairs and auto-lends against its signed roster — with every member keeping their own tick for whether new arrivals inherit that trust, and anyone free to found and host a fedinet of their own on the same machinery. The administration lives on a page of its own. When that day comes, the status bar stops listing what is connected and simply reads: Mesh Online.
