The Dossier.

The people-finding kit — the OSINT workbench inside Casework, dedicated to finding people in the public record and honest about everything it cannot do.

The Dossier SHIPPED · Apex Edge v0.6.8e

Doctrine first

The kit works under rules that stand on its face. Public sources, passive first, keyless first — it is useful with no API keys and no accounts. Every result is cited to the source it came from. Absence is named honestly: "no public record found" is a result; "does not exist" is a claim the kit never makes. Results are leads, not findings — a name match is an unverified lead to disambiguate, never a conclusion about a person. No credential material, ever — breach presence only, never the contents. No face recognition, ever. No plate or DMV lookups. And anything active — probing, scanning, leaning on a target — crosses the LOWC line: lab ranges are free, external targets need the operator's spoken affirmation first, and every run is logged.

The kit — five tabs

Person

The centerpiece. The anchor is the offender-registry check — the public registries searched and linked per hit. On a hit, the registry record becomes the dossier's spine and enrichment fans out from the record's own identity anchors: aliases, locality, public records — with the disambiguation kept on the face of the result, because name collisions are common and a stranger never silently inherits a dossier. Domain and IP facts fold in here as enrichment: a domain the person holds brings its registration facts along.

Username

The handle sweep: one name across the public platforms, hits cited per platform, misses listed as checked-clean — so a negative is a record, not a shrug.

Email

An address worked as a person-key: footprint, sending posture, and breach presence — the fact that an address appears, never what was in the breach.

Phone

Structure facts the number itself states — country, region, line type where a public source says so — plus cited pointers in the number's common formats. The kit cites sources; it does not launder aggregator claims.

Photo

Metadata only. An operator-supplied image gives up its EXIF — where, when, what device — read locally, nothing uploaded. The kit reads a photograph's papers; it never reads a face.

The plan before the pull

The kit's query builder shows its plan before it fires — the keys it will try, the sources it will ask, in the open — and the operator presses go. No silent fan-out, no surprise queries in someone's name. What ran is what the log says ran.

Pivots into cases

Every result can pivot into a case — filed as entities and observables, unverified leads with their provenance on the face of the element, under the same custody rules as everything else in Casework. And the page is only one door: Navi runs the same machinery conversationally, holding the dossier as her context — the keys tried, what has landed, what is still open — with the same citations and the same honesty about absence. The page is the deterministic surface; she is the other way in.
